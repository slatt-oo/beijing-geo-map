# 阶段 2：后端 API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现技术方案 5.4 节的 9 个接口（健康检查已有，新增 8 个），包含严格的参数校验、统一错误格式和 GeoJSON 输出；用真实数据库跑通端到端集成测试，并在文档中记录各接口的实测耗时。

**Architecture:** 三层结构：`handler` 解析、校验参数并写响应；`service` 负责分类编码到 ID 的映射（第一次使用时加载并缓存）、组装返回结构（GeoJSON 与 `{"data": ...}`），并定义各参数的默认值和上限；`repository`（阶段 1 已完成）执行 SQL。handler 只依赖 service 的接口，测试中用假实现替换。

**Tech Stack:** Go 1.26、Gin v1.12.0、pgx v5.11.0、PostgreSQL 16 + PostGIS 3.4。不引入新的依赖。

**Spec:** `docs/01-implementation-plan.md`（第 5 节「阶段 2」）、`docs/02-technical-design.md`（第 5.1 到 5.4 节）、`docs/03-database-design.md`（第 6 节）

## Global Constraints

- 所有工作在 `phase-2-api` 分支上进行，每个任务结束时提交一次。git 提交身份已经配置好，不要修改；环境会在提交信息末尾自动加一行 `Co-authored-by: Cursor`。
- Go 模块路径 `github.com/slatt-oo/beijing-geo-map/backend`，`go 1.26.0`。依赖版本保持不变，不新增依赖。后端测试只用标准库 `testing`。
- 接口约定（技术方案 5.3、5.4 节，含本计划的决定）：
  - 所有接口挂在 `/api/v1` 下，坐标一律是 WGS-84 的 `[经度, 纬度]`。
  - 返回 GeoJSON 的接口（`/districts`、`/pois`、`/pois/nearby`）直接返回 `FeatureCollection`，`Content-Type` 为 `application/geo+json`；其他接口返回 `{"data": ...}`。
  - 错误统一为 `{"error": {"code", "message"}}`：`INVALID_PARAM` 对应 400，`NOT_FOUND` 对应 404，`INTERNAL` 对应 500（message 固定为 `服务器内部错误`）。错误信息使用中文。
  - `/pois` 的返回体顶层始终带 `truncated` 字段；结果多于 `limit` 时为 `true`。截断按 `md5(id)` 打散的固定顺序进行，各分类、各区域按比例保留（用户已选定）。
- 参数规则：经纬度必须是有限数（拒绝 NaN 和 Inf）且在范围内；`limit`、`radius` 的默认值和范围以 `service` 包中的常量为准；`categories` 为逗号分隔的分类编码，缺省或为空表示全部，包含未知编码时返回 400；`q` 去掉首尾空白后按字符数（不是字节数）校验为 1 到 50，拒绝非法 UTF-8 和 NUL 字符；`adcode` 必须是 6 位数字；`id` 必须是正整数。
- 分层约束：handler 不直接调用 repository；service 不接触 HTTP。
- 集成测试：文件名 `*_integration_test.go`，首行 `//go:build integration`，通过 `testdb.New(t, "<唯一名称>")` 获取数据库，管理连接为 `TEST_DATABASE_URL='postgres://geo:geo@localhost:5432/geo?sslmode=disable'`。测试不能写开发库 `geo`。

````markdown
## 6. 典型查询

以下是 repository 中各方法实际执行的 SQL（`backend/internal/repository/`），`$n` 表示参数占位符。点坐标统一以四舍五入到 6 位小数的数值返回，由 service 组装成 GeoJSON；只有区边界以 GeoJSON 字符串返回。

### 6.1 区列表（`DistrictRepo.List`）

```sql
SELECT d.adcode, d.name, d.area_km2::float8,
       round(ST_X(d.center)::numeric, 6)::float8, round(ST_Y(d.center)::numeric, 6)::float8,
       ST_AsGeoJSON(ST_Multi(ST_SimplifyPreserveTopology(d.geom, 0.0001)), 6),
       count(p.id)
FROM district d
LEFT JOIN poi p ON p.district_id = d.id
GROUP BY d.id
ORDER BY d.adcode;
```

`ST_SimplifyPreserveTopology` 是逐个要素独立简化的，相邻两个区的公共边界简化后可能出现极细的缝隙；容差为 0.0001 度（约 10 米）时，城市尺度下肉眼看不出来。外面再套一层 `ST_Multi`：只含一个多边形的 MultiPolygon 简化后会变成 Polygon，套上之后返回的几何类型始终是 MultiPolygon。

### 6.2 区详情（`DistrictRepo.Get`）

```sql
-- 基本信息
SELECT id, adcode, name, area_km2::float8,
       round(ST_X(center)::numeric, 6)::float8, round(ST_Y(center)::numeric, 6)::float8
FROM district
WHERE adcode = $1;

-- 各分类数量（LEFT JOIN 保证数量为 0 的分类也会返回）；$1 = 上一条查询得到的 district.id
SELECT c.code, c.name, count(p.id)
FROM poi_category c
LEFT JOIN poi p ON p.category_id = c.id AND p.district_id = $1
GROUP BY c.id
ORDER BY c.sort_order, c.id;
```

`adcode` 是 `char(6)`，末尾带空格的输入也会匹配，所以接口层必须先校验它是 6 位数字。

### 6.3 我在哪个区（`DistrictRepo.Locate`）

```sql
SELECT adcode, name
FROM district
WHERE ST_Contains(geom, ST_SetSRID(ST_MakePoint($1, $2), 4326))
ORDER BY adcode
LIMIT 1;
```

`ST_MakePoint` 的参数顺序是先经度、后纬度。`ST_Contains` 不包含边界，恰好落在边界线上的点不属于任何区。`ORDER BY adcode` 与导入时重算 `district_id` 的规则一致。

### 6.4 视野范围内的 POI（`POIRepo.InBBox`）

```sql
SELECT p.id, p.name, c.code,
       round(ST_X(p.geom)::numeric, 6)::float8, round(ST_Y(p.geom)::numeric, 6)::float8
FROM poi p
JOIN poi_category c ON c.id = p.category_id
WHERE p.geom && ST_MakeEnvelope($1, $2, $3, $4, 4326)
  AND ($5::smallint[] IS NULL OR p.category_id = ANY($5))
ORDER BY md5(p.id::text), p.id
LIMIT $6;  -- $6 = limit + 1
```

- 查询时多取 1 条：实际返回 `limit + 1` 条说明结果被截断，丢掉最后一条后设置 `truncated: true`，比额外执行 `count(*)` 更省。
- 按 `md5(id)` 排序：id 按导入顺序分配，同一分类的 id 连在一起（例如 411 个地铁站的 id 全部排在最后）。按 id 截断会让排在后面的分类整类缺失；按 `md5(id)` 打散后，截断时各分类、各区域按比例保留，并且顺序固定，同一请求总是得到同样的结果。
- 分类过滤：Go 侧把 nil 或空的分类 ID 列表都转成 SQL `NULL`，表示不过滤。

### 6.5 POI 详情（`POIRepo.Get`）

```sql
SELECT p.id, p.name, p.name_en, p.osm_type, p.osm_id, p.address, p.tags,
       c.id, c.code, c.name, c.color,
       d.adcode, d.name,
       round(ST_X(p.geom)::numeric, 6)::float8, round(ST_Y(p.geom)::numeric, 6)::float8
FROM poi p
JOIN poi_category c ON c.id = p.category_id
LEFT JOIN district d ON d.id = p.district_id
WHERE p.id = $1;
```

### 6.6 搜索（`POIRepo.Search`）

```sql
-- $1 = '%' || 转义后的关键词 || '%'，$2 = 原始关键词，$3 = limit
SELECT p.id, p.name, c.code,
       round(ST_X(p.geom)::numeric, 6)::float8, round(ST_Y(p.geom)::numeric, 6)::float8,
       d.name
FROM poi p
JOIN poi_category c ON c.id = p.category_id
LEFT JOIN district d ON d.id = p.district_id
WHERE p.name ILIKE $1::text
ORDER BY (p.name = $2::text) DESC, similarity(p.name, $2::text) DESC, length(p.name), p.id
LIMIT $3;
```

PostgreSQL 中 `LIKE` / `ILIKE` 的默认转义字符是反斜杠。Go 代码会把关键词中的 `\`、`%`、`_` 分别替换成 `\\`、`\%`、`\_`。

### 6.7 附近查询（`POIRepo.Nearby`）

```sql
-- $1 = lng, $2 = lat, $3 = 半径（米）, $4 = 分类 ID 数组或 NULL, $5 = limit
WITH origin AS (
    SELECT ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography AS g
)
SELECT p.id, p.name, c.code,
       round(ST_X(p.geom)::numeric, 6)::float8, round(ST_Y(p.geom)::numeric, 6)::float8,
       round(ST_Distance(p.geom::geography, o.g))::int AS distance_m
FROM poi p
JOIN poi_category c ON c.id = p.category_id
CROSS JOIN origin o
WHERE ST_DWithin(p.geom::geography, o.g, $3)
  AND ($4::smallint[] IS NULL OR p.category_id = ANY($4))
ORDER BY distance_m, p.id
LIMIT $5;
```

`ST_DWithin` 会先用 `poi_geog_gist` 索引按外包框过滤，再计算精确距离。过滤条件不能写成 `ST_Distance(...) <= r`，那样用不上索引；集成测试会对这里的真实 SQL 执行 `EXPLAIN`，确认用上了索引。

### 6.8 分类列表（`CategoryRepo.List`）

```sql
SELECT id, code, name, color FROM poi_category ORDER BY sort_order, id;
```

`sort_order` 不是唯一的，`id` 作为兜底保证顺序固定。
````

```go
package service

import (
	"context"
	"fmt"
	"slices"
	"sync"

	"github.com/slatt-oo/beijing-geo-map/backend/internal/model"
)

type CategoryLister interface {
	List(ctx context.Context) ([]model.Category, error)
}

// Catalog 在第一次使用时从数据库加载分类并缓存；加载失败时下次调用会重试，
// 因此数据库暂时不可用不会妨碍服务启动。
type Catalog struct {
	repo CategoryLister

	mu         sync.Mutex
	loaded     bool
	categories []Category
	ids        map[string]int16
}

func NewCatalog(repo CategoryLister) *Catalog {
	return &Catalog{repo: repo}
}

func (c *Catalog) List(ctx context.Context) ([]Category, error) {
	if err := c.load(ctx); err != nil {
		return nil, err
	}
	return slices.Clone(c.categories), nil
}

// IDs 把分类编码转换为 ID。codes 为空时返回 nil，表示不按分类过滤。
func (c *Catalog) IDs(ctx context.Context, codes []string) ([]int16, error) {
	if len(codes) == 0 {
		return nil, nil
	}
	if err := c.load(ctx); err != nil {
		return nil, err
	}
	ids := make([]int16, 0, len(codes))
	for _, code := range codes {
		id, ok := c.ids[code]
		if !ok {
			return nil, UnknownCategoryError{Code: code}
		}
		ids = append(ids, id)
	}
	return ids, nil
}

func (c *Catalog) load(ctx context.Context) error {
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.loaded {
		return nil
	}
	rows, err := c.repo.List(ctx)
	if err != nil {
		return fmt.Errorf("load categories: %w", err)
	}
	c.categories = make([]Category, 0, len(rows))
	c.ids = make(map[string]int16, len(rows))
	for _, r := range rows {
		c.categories = append(c.categories, Category{Code: r.Code, Name: r.Name, Color: r.Color})
		c.ids[r.Code] = r.ID
	}
	c.loaded = true
	return nil
}
```

```go
package service

import (
	"context"

	"github.com/slatt-oo/beijing-geo-map/backend/internal/model"
)

type DistrictRepository interface {
	List(ctx context.Context) ([]model.DistrictFeature, error)
	Get(ctx context.Context, adcode string) (model.DistrictDetail, error)
	Locate(ctx context.Context, lng, lat float64) (*model.DistrictRef, error)
}

type DistrictService struct {
	repo DistrictRepository
}

func NewDistrictService(repo DistrictRepository) *DistrictService {
	return &DistrictService{repo: repo}
}

func (s *DistrictService) List(ctx context.Context) (DistrictCollection, error) {
	districts, err := s.repo.List(ctx)
	if err != nil {
		return DistrictCollection{}, err
	}
	features := make([]DistrictFeature, 0, len(districts))
	for _, d := range districts {
		features = append(features, DistrictFeature{
			Type:     "Feature",
			Geometry: d.Geometry,
			Properties: DistrictProperties{
				Adcode:   d.Adcode,
				Name:     d.Name,
				AreaKm2:  d.AreaKm2,
				POICount: d.POICount,
				Center:   d.Center,
			},
		})
	}
	return DistrictCollection{Type: "FeatureCollection", Features: features}, nil
}

func (s *DistrictService) Get(ctx context.Context, adcode string) (DistrictDetail, error) {
	d, err := s.repo.Get(ctx, adcode)
	if err != nil {
		return DistrictDetail{}, err
	}
	counts := make([]CategoryCount, 0, len(d.POICounts))
	for _, c := range d.POICounts {
		counts = append(counts, CategoryCount{Code: c.Code, Name: c.Name, Count: c.Count})
	}
	return DistrictDetail{Adcode: d.Adcode, Name: d.Name, AreaKm2: d.AreaKm2, Center: d.Center, POICounts: counts}, nil
}

// Locate 在点不属于任何区时返回 nil, nil。
func (s *DistrictService) Locate(ctx context.Context, lng, lat float64) (*DistrictRef, error) {
	ref, err := s.repo.Locate(ctx, lng, lat)
	if err != nil || ref == nil {
		return nil, err
	}
	return &DistrictRef{Adcode: ref.Adcode, Name: ref.Name}, nil
}
```

```go
	Limit      int

func NewPOIService(repo POIRepository, catalog *Catalog) *POIService {
	return &POIService{repo: repo, catalog: catalog}
}

func (s *POIService) Categories(ctx context.Context) ([]Category, error) {

func (s *POIService) InBBox(ctx context.Context, q BBoxQuery) (POICollection, error) {
	ids, err := s.catalog.IDs(ctx, q.Categories)
	if err != nil {
		return POICollection{}, err
	}
	pois, truncated, err := s.repo.InBBox(ctx, q.Box, ids, q.Limit)

		})
	}

}

	p, err := s.repo.Get(ctx, id)
	if err != nil {
		return POIDetail{}, err

		ID:       p.ID,

	}

		detail.District = &DistrictRef{Adcode: p.District.Adcode, Name: p.District.Name}
	}
```

```go
package handler

import (
	"fmt"
	"math"
	"regexp"
	"strconv"
	"strings"
	"unicode/utf8"

	"github.com/slatt-oo/beijing-geo-map/backend/internal/model"
	"github.com/slatt-oo/beijing-geo-map/backend/internal/service"
)

type paramError struct {
	message string
}

func (e paramError) Error() string {
	return e.message
}

func invalidParam(format string, args ...any) error {
	return paramError{message: fmt.Sprintf(format, args...)}
}

// strconv.ParseFloat 接受 "NaN"、"Inf"，而 NaN 能绕过 v < min || v > max 这样的范围检查，所以必须显式拒绝。
func parseFinite(name, raw string) (float64, error) {
	v, err := strconv.ParseFloat(strings.TrimSpace(raw), 64)
	if err != nil || math.IsNaN(v) || math.IsInf(v, 0) {
		return 0, invalidParam("%s 必须是有限的数字", name)
	}
	return v, nil
}

func parseRequiredFloat(name, raw string, min, max float64) (float64, error) {
	if strings.TrimSpace(raw) == "" {
		return 0, invalidParam("缺少参数 %s", name)
	}
	return parseFloatInRange(name, raw, min, max)
}

func parseFloatInRange(name, raw string, min, max float64) (float64, error) {
	v, err := parseFinite(name, raw)
	if err != nil {
		return 0, err
	}
	if v < min || v > max {
		return 0, invalidParam("%s 必须在 %g 到 %g 之间", name, min, max)
	}
	return v, nil
}

func parseLngLat(rawLng, rawLat string) (float64, float64, error) {
	lng, err := parseRequiredFloat("lng", rawLng, -180, 180)
	if err != nil {
		return 0, 0, err
	}
	lat, err := parseRequiredFloat("lat", rawLat, -90, 90)
	if err != nil {
		return 0, 0, err
	}
	return lng, lat, nil
}

func parseOptionalFloat(name, raw string, def, min, max float64) (float64, error) {
	if strings.TrimSpace(raw) == "" {
		return def, nil
	}
	return parseFloatInRange(name, raw, min, max)
}

func parseOptionalInt(name, raw string, def, min, max int) (int, error) {
	raw = strings.TrimSpace(raw)
	if raw == "" {
		return def, nil
	}
	v, err := strconv.Atoi(raw)
	if err != nil || v < min || v > max {
		return 0, invalidParam("%s 必须是 %d 到 %d 之间的整数", name, min, max)
	}
	return v, nil
}

func parseBBox(raw string) (model.BBox, error) {
	if strings.TrimSpace(raw) == "" {
		return model.BBox{}, invalidParam("缺少参数 bbox")
	}
	parts := strings.Split(raw, ",")
	if len(parts) != 4 {
		return model.BBox{}, invalidParam("bbox 格式应为 minLng,minLat,maxLng,maxLat")
	}
	var v [4]float64
	for i, part := range parts {
		f, err := parseFinite("bbox", part)
		if err != nil {
			return model.BBox{}, err
		}
		v[i] = f
	}
	box := model.BBox{MinLng: v[0], MinLat: v[1], MaxLng: v[2], MaxLat: v[3]}
	if box.MinLng < -180 || box.MaxLng > 180 || box.MinLat < -90 || box.MaxLat > 90 {
		return model.BBox{}, invalidParam("bbox 超出经纬度范围")
	}
	if box.MinLng >= box.MaxLng || box.MinLat >= box.MaxLat {
		return model.BBox{}, invalidParam("bbox 的最小值必须小于最大值")
	}
	return box, nil
}

func parseCategories(raw string) []string {
	var codes []string
	for _, part := range strings.Split(raw, ",") {
		if code := strings.TrimSpace(part); code != "" {
			codes = append(codes, code)
		}
	}
	return codes
}

// PostgreSQL 会对非法 UTF-8 和 NUL 字符报错（SQLSTATE 22021），必须在入口拒绝；长度按字符数计算，一个汉字算一个。
func parseQuery(raw string) (string, error) {
	if !utf8.ValidString(raw) || strings.ContainsRune(raw, 0) {
		return "", invalidParam("q 包含非法字符")
	}
	q := strings.TrimSpace(raw)
	n := utf8.RuneCountInString(q)
	if n == 0 {
		return "", invalidParam("缺少参数 q")
	}
	if n > service.MaxQueryRunes {
		return "", invalidParam("q 不能超过 %d 个字符", service.MaxQueryRunes)
	}
	return q, nil
}

var adcodePattern = regexp.MustCompile(`^[0-9]{6}$`)

func parseAdcode(raw string) (string, error) {
	if !adcodePattern.MatchString(raw) {
		return "", invalidParam("adcode 必须是 6 位数字")
	}
	return raw, nil
}

func parseID(raw string) (int64, error) {
	id, err := strconv.ParseInt(raw, 10, 64)
	if err != nil || id <= 0 {
		return 0, invalidParam("id 必须是正整数")
	}
	return id, nil
}
```

```go
const geoJSONContentType = "application/geo+json"

func writeGeoJSON(c *gin.Context, v any) {
	body, err := json.Marshal(v)
	if err != nil {
		slog.ErrorContext(c.Request.Context(), "encode geojson response", "err", err)
		writeInternal(c)
		return
	}
	c.Data(http.StatusOK, geoJSONContentType, body)
}

func writeParamError(c *gin.Context, err error) {
	writeError(c, http.StatusBadRequest, CodeInvalidParam, err.Error())
}

// writeServiceError 把 service 返回的错误映射为 HTTP 响应。notFoundMessage 为空时，ErrNotFound 也按内部错误处理。
func writeServiceError(c *gin.Context, err error, notFoundMessage string) {
	var unknown service.UnknownCategoryError
	switch {
	case errors.As(err, &unknown):
		writeError(c, http.StatusBadRequest, CodeInvalidParam, "未知的分类编码："+unknown.Code)
	case notFoundMessage != "" && errors.Is(err, service.ErrNotFound):
		writeError(c, http.StatusNotFound, CodeNotFound, notFoundMessage)
	default:
		slog.ErrorContext(c.Request.Context(), "request failed", "path", c.Request.URL.Path, "err", err)
		writeInternal(c)
	}
}
```

```go
			writeParamError(c, err)
			return
		}
		hits, err := s.Search(c, q, limit)
		if err != nil {
			writeServiceError(c, err, "")
			return
		}
		writeData(c, hits)
	}
}

func nearbyPOIs(s POIService) gin.HandlerFunc {
	return func(c *gin.Context) {
		lng, lat, err := parseLngLat(c.Query("lng"), c.Query("lat"))
		if err != nil {
			writeParamError(c, err)
			return
		}
		radius, err := parseOptionalFloat("radius", c.Query("radius"),
			service.DefaultNearbyRadiusM, service.MinNearbyRadiusM, service.MaxNearbyRadiusM)
		if err != nil {
			writeParamError(c, err)
			return
		}
		limit, err := parseOptionalInt("limit", c.Query("limit"), service.DefaultNearbyLimit, 1, service.MaxNearbyLimit)
		if err != nil {
			writeParamError(c, err)
			return
		}
		pois, err := s.Nearby(c, service.NearbyQuery{
			Lng: lng, Lat: lat, RadiusM: radius, Categories: parseCategories(c.Query("categories")), Limit: limit,
		})
		if err != nil {
			writeServiceError(c, err, "")
			return
		}
		writeGeoJSON(c, pois)
	}
}
```
