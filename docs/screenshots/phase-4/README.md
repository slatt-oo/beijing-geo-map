# 阶段 4 验收记录

验收日期：2026-10-15。环境：先执行 `docker compose down -v` 删除数据卷，再执行 `FRONTEND_PORT=18080 docker compose up --build`（生产构建，经 nginx 访问），浏览器窗口 1920×1080（Cursor 内置浏览器，基于 Chromium）。导入日志：`districts: 16`、`pois: 4112`、`pois_with_district: 4098`、`skipped_outside_region: 1`，与阶段 3 相同。

对应实现文档第 5 节「阶段 4」的验收标准，即技术方案第 10 节的手工验证清单。第 1 到 5 项在阶段 3 已逐项截图（见 [阶段 3 验收记录](../phase-3/README.md)），这次从零启动后复查了首页。

**定位的模拟方式：** 内置浏览器拿不到真实位置，第 6、7、11 项用 Chrome DevTools Protocol 的 `Emulation.setGeolocationOverride` 模拟。不带坐标时浏览器返回「位置不可用」（第 7、11 项）；带坐标时返回给定的 WGS-84 坐标（第 6 项，天安门城楼 116.3911, 39.9073，精度 150 米）。没有在真实的 Safari 中测试。

**提示条：** 普通提示 4 秒后自动消失，而截图工具两次操作之间的间隔比这更长。所以截图时在页面里把这 4 秒临时延长，代码没有改动。自动消失本身另外用页面记录确认过：「你在海淀区」出现 4.0 秒后消失。
